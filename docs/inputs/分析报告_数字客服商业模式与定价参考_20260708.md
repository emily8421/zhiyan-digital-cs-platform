# 分析报告：数字客服商业模式与定价参考

**用途**：为数字客服定价决策提供市场参照依据，供向古晶光电、乐式科技报价前使用
**性质**：内部分析材料，市场数据附来源链接，古镇客户付费习惯部分基于一手访谈推测，尚未经实际报价验证
**整理日期**：2026年7月8日

---

## 一、结论先行

市场上同类产品（企业微信SCRM、数字客服SaaS）的定价区间已经比较清晰，中小企业基础套餐普遍落在**几千到一万多元/年**，这给了一个大致的价格锚点。但这份报告更重要的发现是：**国内中小企业对SaaS订阅制普遍存在结构性的付费抵触**，这个抵触不是知衍一家会遇到的问题，而是整个行业的共性障碍。古晶光电、乐式科技的付费习惯目前还没有一手验证，需要在定价策略里预留应对这种抵触的空间，而不是直接套用"参考同行定价"这么简单。

## 三、国内中小企业SaaS付费习惯的结构性特点

这一节的内容不是针对古镇的一手调研，而是国内SaaS行业的普遍经验总结，用来提醒你古晶、乐式很可能也会表现出类似的行为模式。

### 3.1 付费意识和习惯的培育不足

国内中小企业SaaS市场尚未完全激活，**用户付费习惯培育不足**，多数企业发展仍处于"开源"而非"节流"阶段，对内部效率提升类工具的付费意愿天然弱于"能直接带来新客户/新订单"的工具（[36氪·中国SaaS商业模式解析](https://36kr.com/p/1138941247341705)）。

### 3.2 "先免费后付费"的用户心理

**国内用户普遍认为SaaS产品应该先免费使用，为增值服务部分付费**；如果产品一上来就收费，用户天然会产生抵触心理——这与美国用户"不收费反而怀疑产品有问题"的心态完全相反（[订阅的力量·知乎](https://zhuanlan.zhihu.com/p/1912824422424879110)）。

### 3.3 买断制心理依然存在，尤其是采购预算属性的问题

不少企业（尤其是历史上习惯"资产采购"而非"按月付费"预算模式的传统企业）更容易接受一次性买断的模式，只有近两年才逐渐有更多中大型客户开始接受订阅制（[本土化SaaS出路·牛透社](https://www.niutoushe.com/81300)）。**制造业工厂的采购习惯，历史上更接近"买设备"逻辑（一次性支出，验收入账），而非"订阅服务"逻辑**，这一点虽然没有专门的古镇数据，但与古晶光电这类传统制造业企业的整体决策模式是相符的。

### 3.4 中小企业生命周期短，影响续费可持续性

国内中小企业平均寿命约2.5年，只有三分之一能撑过三年，这意味着即便产品做到极致，SaaS服务商每年也会面临客户自然流失（[SaaS商业模式解析](https://www.huangshuxiu.com/%E5%95%86%E4%B8%9A%E6%A8%A1%E5%BC%8F/277.html)）。**这一点提醒知衍：不能把商业模式完全押注在"长期订阅续费"上，需要在首年就实现足够的现金回收**，不能假设客户会稳定续费三五年。

## 四、结合一手证据推测古晶、乐式的付费习惯（尚未验证，仅作定价策略参考）

### 4.1 古晶光电：产品型制造企业，可能更接近"买断/按效果付费"心理

古晶光电此前有过销售商城项目夭折的经历（技术对接复杂度挡住了项目），说明企业内部对"数字化投入"是有过一次尝试和挫败经验的，这意味着：
- 张总很可能对"先看到效果、再决定投入"这种验证逻辑更容易接受，而不是一开始就签一份年费合同
- 作为传统制造业老板，更可能倾向于"这次花的钱能不能马上看到少雇人、少出错"这种直接效果计算，而非"数字化转型"这种长期投入逻辑

### 4.2 乐式科技：项目型企业，可能更接受"按项目/按阶段付费"

乐式本身是关联方，且业务模式是项目制（方案开发、生产跟单分阶段收费），**更可能习惯"按阶段付费"而非"按月订阅"**，这与他们自己的业务收费逻辑是一致的，向乐式报价时或许可以参照这个逻辑设计付费节点。

### 4.3 需要如实标注的局限

以上两点是基于两家企业已知的经营特征做出的**合理推测，不是已经验证的付费意愿**。实际报价时，古晶、乐式的真实反应完全可能与这里的推测不同，需要通过实际报价对话来验证，不能把这一节的推测当作确定性结论使用。

## 五、定价结构建议

综合以上市场参照和付费习惯分析，建议采用"低门槛启动+效果验证后再深化收费"的阶梯结构，而不是一次性推销年费订阅：

### 阶段一：验证期（低成本或免费）

- 用现有数据跑通一个具体场景（如古晶的产品咨询知识库），以demo或短期免费试用的方式，让客户看到"询盘响应变快了""老板能看到每日小结"这类直接可感知的效果
- 这个阶段不建议直接谈订阅费用，对应第三节里提到的"国内用户对先免费后付费"心理预期

### 阶段二：转化期（首次付费，控制在客户容易接受的量级）

参考市场基础套餐价位（8000-12000元/年是行业常见的中小企业入门档位），但考虑到知衍目前没有品牌背书、没有案例积累，建议**低于市场平均基础套餐定价**，作为"新产品打入市场"的策略性定价，同时明确告诉客户这是早期客户价格，为后续案例背书换取一定折扣空间。

### 阶段三：深化期（客户认可后，往订阅+增值服务方向发展）

如果古晶验证成功，可以在原有基础上增加场景包（覆盖售后、进度查询等更多场景），按增量场景收费，逐步把客户从"低价试用"转向"按价值付费"，避免第一年就把价格锚点定得过低导致后续提价困难。

### 关于交付形态的定价对应

结合此前《产品构想》文档里已经列出的交付形态：

| 交付形态 | 建议定价逻辑 |
|---------|-------------|
| H5对话页（当前Demo形态） | 验证期免费或象征性收费，重点在验证效果 |
| 微信公众号 | 转化期首选形态，按年订阅，参考市场基础套餐但适度下浮 |
| 嵌入OA/内部系统（乐式提出的需求） | 按项目定制收费+年维护费，比照乐式自身项目制收费习惯 |

## 六、需要如实提醒的风险

1. **这份报告里的市场定价数据，来自SCRM/数字客服这类相对成熟的产品品类，知衍目前还没有案例、没有品牌背书，直接对标同行定价可能偏乐观**，实际报价时可能需要比这里列出的区间更低，才能换取第一个真实付费客户。

2. **国内中小企业SaaS续费率低、企业生命周期短这两个结构性问题，意味着不能把商业模式完全建立在"订阅续费"这个假设上**，需要认真考虑首年现金回收的节奏，以及是否要设计"买断+维护费"这种更接近古镇企业采购心理的收费方式，而不是照搬互联网SaaS的订阅逻辑。

3. **第四节关于古晶、乐式付费习惯的推测，尚未经过一手验证**，建议把这份报告的定价建议当作报价前的参考框架，而不是可以直接照抄的最终报价单，实际报价后需要把客户的真实反馈更新回这份文档。
