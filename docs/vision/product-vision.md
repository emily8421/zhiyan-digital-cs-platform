## 1. 产品定位

知衍数字客服统一平台面向古镇产业带及类似中小企业，解决“靠微信做生意、靠人盯群”的客户沟通困境。平台以 H5 对话、知识库问答、场景包、Mock 业务查询、员工通知和运营看板为基础，把售前咨询、售中进度、售后规则与知识缺口沉淀成可演示、可迭代的数字客服流程。

产品的核心价值不是替代全部人工，而是先把高频、低风险、可规则化的问题稳定接住；遇到高风险、无依据或需要业务判断的问题，明确转人工并留下可追溯记录。长期形态可扩展到公众号、小程序、客户自有系统嵌入、真实 CRM/ERP/OA/飞书项目集成和多租户运营平台。

## 3. 目标体验

- **客户侧轻入口**：Phase1 使用 H5 对话页，客户扫码即用；不依赖企业微信客户群自动回复。
- **回答有依据**：系统只能基于知识库、规则、场景包或 Mock 数据回答；无依据时说明无法确认并转人工。
- **风险可兜底**：投诉、赔付、合同、价格、交期承诺、隐私数据等高风险问题不自动承诺。
- **运营可追踪**：每次答不上、转人工、Mock 查询、通知发送都能留下记录，便于复盘。
- **老板看结果**：用日报 / 控制台汇总“问了什么、答了什么、谁还没跟”。

## 5. 非目标与边界

- Phase1 不接入真实企业微信会话存档、真实飞书组织数据、真实 CRM/ERP/OA/工单系统。
- Phase1 不处理真实客户隐私数据、合同、报价、订单或生产会话。
- Phase1 不启用本地大模型推理、模型训练或生产规模向量索引。
- 未经人工确认，不调用外部付费 API、LLM API 或新增 Docker 镜像 / 依赖。
- 企业微信客户群“机器人自动对外回复”前提已被证伪，客户侧入口默认改为 H5。
- 系统不得为没有来源的事实、价格、交期、赔付、法律责任或售后承诺编造答案。
