## 1. 基本原则

- 最小权限：首个 Phase3 PoC 默认只读，不做写回生产系统。
- 最小数据：只取验收场景必需字段，不同步全量客户、订单、合同或工单数据。
- 默认不信任：外部接口、回调、LLM、Webhook 和导入文件都需校验来源、权限与数据范围。
- 可追溯：所有外部系统返回的业务事实必须保留 `source_ref` / 请求 ID / 系统来源，前端展示来源标识。
- 不编造：外部系统无记录、超时、失败或字段不足时，必须返回无依据 / 转人工，不得补全业务事实。
- 不落密钥：API key、secret、token、密码、cookie、私钥不得写入仓库、日志、截图或续接文件。

## 2. 数据分类与处理规则

| 数据分类 | 示例 | 默认处理 | 是否可入库 | 是否可展示给客户 | 审批要求 |
|---|---|---|---|---|---|
| Mock / 示例数据 | Demo 单号、Mock 项目、样例知识 | 可用于开发与演示，需标 Mock | 可 | 可，需标 Mock | 项目内确认 |
| 业务配置 | 场景包、规则、知识条目 | 可入库，需来源追溯 | 可 | 可展示经审核内容 | 运营确认 |
| 客户个人信息 | 手机、姓名、地址、微信 / 飞书 ID | 默认不采集；必须脱敏 | 默认否 | 默认否 | 客户授权 + 安全评审 |
| 商业敏感信息 | 合同、报价、成本、赔付、库存、交期承诺 | 默认不展示；高风险转人工 | 默认否 | 默认否 | 业务负责人 + 安全评审 |
| 生产业务记录 | 订单、项目、工单、售后处理记录 | 默认只读最小字段 | 条件允许 | 仅展示授权字段 | 客户授权 + 字段映射 |
| 凭据 / 密钥 | API key、secret、token、私钥 | 严禁入库 / 入日志 | 否 | 否 | 专人保管 + 安全渠道交付 |

## 3. 凭据与配置边界

| 检查项 | 要求 | 当前状态 |
|---|---|---|
| 凭据交付 | 仅通过客户认可的安全渠道交付，不写入 Git / 文档 / IM 明文 | 待确认 |
| 本地配置 | 使用环境变量或本机 `.env`，并确保 `.gitignore` 覆盖 | 待确认 |
| 权限范围 | 首个 PoC 使用只读权限；写权限需单独评审 | 待确认 |
| 有效期 | 测试凭据需有有效期、吊销方式和负责人 | 待确认 |
| 轮换策略 | 生产前需定义密钥轮换、泄露处置和审计流程 | 待确认 |
| 日志脱敏 | 不记录 token、Authorization、cookie、手机号、身份证、合同金额等敏感字段 | 待确认 |

## 4. 外部接口访问边界

| 检查项 | Go 条件 | No-Go 条件 |
|---|---|---|
| 网络访问 | 明确访问域名、IP 白名单、VPN / 代理和环境 | 未说明访问路径或需访问未知生产内网 |
| 接口权限 | 只读范围明确，接口文档可追溯 | 需要管理员或全量权限才能测试 |
| 限流 / 超时 | 有限流、超时、重试和降级策略 | 未知限流且可能影响生产系统 |
| 错误码 | 错误码和异常场景可映射 | 失败时只能返回不透明错误 |
| 回调 | 有验签、重放防护和事件范围 | 未验签或事件包含未授权敏感数据 |
| 降级 | 接口失败可回退 Mock / 转人工 | 接口失败会导致编造或错误承诺 |

## 5. 日志、审计与留痕

| 日志对象 | 允许记录 | 禁止记录 | 备注 |
|---|---|---|---|
| API 请求 | request_id、系统名、接口名、耗时、状态码 | token、完整 URL 敏感 query、请求体敏感字段 | 必须可关联排障 |
| API 响应 | 状态码、错误码、脱敏摘要 | 完整生产响应、客户隐私、合同 / 报价细节 | 仅保留必要摘要 |
| 用户操作 | 角色、操作类型、记录 ID、时间 | 密码、凭据、敏感原文 | Phase4 可扩展审计表 |
| LLM 调用 | 默认不调用；如 sandbox，只记录脱敏 prompt 摘要 | 真实客户隐私、合同、订单、联系方式 | 真实启用需单独授权 |

## 6. 前端展示边界

| 场景 | 展示规则 | 禁止事项 |
|---|---|---|
| 订单 / 项目进度 | 展示已授权字段、更新时间、来源系统和环境标识 | 不展示内部备注、成本、合同、未确认交期 |
| 工单 / 售后 | 展示工单状态和可公开处理进度 | 不展示内部负责人隐私、赔付裁决、敏感备注 |
| 无记录 / 失败 | 展示“未查询到依据”或转人工 | 不编造状态、ETA、赔付或承诺 |
| 高风险问题 | 强制转人工，保留风险提示 | 不自动答复法律、合同、赔付、隐私相关结论 |

## 7. LLM 与外部 SaaS 边界

| 检查项 | 要求 | 当前状态 |
|---|---|---|
| 默认状态 | `disabled` 或 Mock，不自动调用真实 LLM | 保持关闭 |
| 数据发送 | 未经授权不得向外部 LLM 发送真实客户数据 | No-Go |
| 成本授权 | 真实调用前需有额度、限流、超时和熔断 | 未确认 |
| 证据约束 | LLM 输出必须基于检索证据，不可编造 | 已评估，未启用 |
| 兜底 | 高风险 / 无依据 / 超时转人工 | 必须保留 |
