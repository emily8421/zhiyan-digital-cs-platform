## 7. 文案、信息密度与可理解性

- **用户需一眼看到**：H5 — Demo 标识 + 依据类型；Console — 待跟进 / 缺口角标 + 风险等级。
- **容易误解的表达**：「订单进度」「预计交期」易被当作真实数据 → 必须挂 Mock 标识。
- **需要免责 / 风险提示的位置**：H5 顶栏 Demo 标识 + 转人工说明；Console 详情栏 Mock 标识。
