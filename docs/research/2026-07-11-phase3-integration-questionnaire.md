## 1. 使用方式

- 本问卷用于 Phase3 真实集成前置调研，不要求在本文写入真实密钥、token、密码、客户隐私或生产数据。
- 若涉及真实凭据，只填写“凭据类型、保管人、交付方式、有效期、权限范围”，不要把凭据值写入仓库。
- 若客户无法提供沙箱 / 测试账号，真实集成默认为 No-Go，只允许继续 Mock / sandbox 骨架设计。
- 每个系统单独填写一份系统清单；首个 PoC 建议只选一个只读查询场景，避免一次接入多系统。

## 9. 建议下一步

1. 由业务负责人选择首个 Phase3 PoC 场景：订单进度只读查询或项目进度只读查询。
2. 由客户 IT 填写系统清单、接口文档、沙箱账号和网络要求。
3. 由安全 / 合规负责人完成数据边界与授权确认。
4. 问卷完成前，仅允许继续 Mock / sandbox 骨架设计，不启动真实接入实现。
