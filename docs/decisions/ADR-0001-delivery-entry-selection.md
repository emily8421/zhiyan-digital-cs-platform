# ADR-0001 客户入口选择：Phase1 采用 H5

> **定位：决策记录。** 本文记录 Phase1 客户侧入口选择，来源于输入评审与交付形态材料。

## 状态

已确认（2026-07-04）。

## 背景

输入材料包含 H5、公众号、企业微信机器人、桌面端、API 嵌入、小程序等交付形态。场景包中曾出现企业微信客户群自动回复构想，但评审记录已指出该前提在 Sprint-0 被证伪，新项目客户入口用 H5 规避。

## 决策

Phase1 客户侧入口采用 H5 对话页；员工侧采用 Web 控制台；飞书通知仅作为 Mock / 适配层演示。

## 理由

- H5 零安装、扫码即用，适合 Demo。
- 不依赖客户企业微信权限或客户群机器人能力。
- 便于同一后端服务后续扩展公众号、小程序或 API 嵌入。

## 影响

- `frontend/` 保留，至少包含 H5 与 Web 控制台。
- `docs/07-api-spec.md` 必须定义 H5 / Web REST API。
- 企业微信客户群自动对外回复不进入 Phase1。

## 后续复核

Phase2 可根据试点客户反馈重新评估公众号、小程序、微信客服或 API 嵌入。
