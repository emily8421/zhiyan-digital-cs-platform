# ADR-0002 外部系统集成：Phase1 Mock 优先

> **定位：决策记录。** 本文记录订单、项目、售后、通知等外部集成的 Phase1 边界。

## 状态

草稿，待人工确认。

## 背景

产品愿景包含订单进度、项目进度、售后工单、飞书通知、CRM / ERP / OA / 飞书项目等能力，但当前没有确认真实接口、授权、凭据、安全和测试环境。

## 决策

Phase1 所有外部系统能力通过 Mock 适配层演示，不连接真实系统。

## 理由

- 避免真实客户隐私和生产数据风险。
- 保证本机 Demo 可运行。
- 先验证产品流程，再决定真实系统集成优先级。

## 影响

- `docs/design/mock-integrations.md` 作为 Phase1 外部能力详细设计。
- API 返回必须明确 `mock: true`。
- 真实飞书通知、CRM / ERP / OA / 工单接入推迟到 Phase2+ / Phase3。

## 升级条件

必须先确认外部系统测试环境、凭据管理、数据脱敏、审计、错误处理和授权范围。
